# Relatórios de revisão

Um arquivo por verbete, `<id>.md`, escrito pelo agente revisor-editorial no fechamento de cada ciclo. Traz a tabela dos dez pontos conferidos, os PROBLEMAs (com o trecho e o que a fonte diz), as ATENÇÕES (fonte única, homônimo), o que foi corrigido direto e a linha "Pronto para pull request: sim/não".

O redator lê este arquivo antes de reescrever um verbete `devolvido`. A descrição do lote (`dados/lotes/lote-NN.md`) é montada a partir daqui. O Helton usa como guia na revisão humana.
